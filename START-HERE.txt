Storefront Simulator — chay ngay
=================================

Ban zip nay da kem san node_modules va dist, nen chi can Node 20 tro len.
Mo terminal TRONG thu muc nay roi go:

    node dist/cli.js dashboard

Roi mo http://127.0.0.1:7317

Bam "New profile", roi "Start" tren tile. Tile tu stream truc tiep,
khong can bam gi them. Bam vao hinh de phong to.

Windows: mo thu muc nay trong File Explorer, go  cmd  vao thanh dia chi
roi Enter — la vao dung cho.


Neu bao thieu Chromium
----------------------
Lan chay dau can mot trinh duyet. Chon 1 trong 2:

  1) Tai Chromium da patch cua CloakBrowser (~1GB, chi 1 lan):
         npx cloakbrowser install

  2) Hoac dung Chrome/Edge da cai san — khong tai gi, nhung khong co
     lop fingerprint cua CloakBrowser. Mo storefront-sim.config.json,
     trong phan "browser" them:
         "allowFallbackBrowser": true
     Tool tu tim Chrome/Edge tren may.


Cac lenh khac
-------------
    node dist/cli.js dashboard --pace 2     nhanh gap doi
    node dist/cli.js probe --storefront https://shop-cua-ban.com
    node dist/cli.js verify                 xem browser phoi ra gi
    node dist/cli.js run --duration 15      chay 1 session bang CLI
    node dist/cli.js --help


Chinh hanh vi
-------------
Mo storefront-sim.config.json:

  "storefront"        shop muc tieu
  "actionPause"       khoang cach giua 2 hanh dong (mac dinh 2000-3000ms)
  "maxActionsPerPage" so hanh dong toi da tren 1 trang (mac dinh 14)
  "speedFactor"       chia deu moi delay (2 = nhanh gap doi)
  "session.durationMs" do dai 1 session (mac dinh 15 phut)


Sua code roi build lai
----------------------
    npm install
    npm run build
    npm test
